# 五部古希腊戏剧全文（公版英文译本）

本目录收录五部古希腊悲剧的完整公版英文译文，取自 Project Gutenberg 与 Wikisource。选择公版英文译本，是为了确保可以合法保存和使用；现代中文全译本（如罗念生译本）通常仍受译者著作权保护，因此未从非授权网站转载。

## 文件与版本

1. `01_埃斯库罗斯_被缚的普罗米修斯_Prometheus_Bound.txt`
   - 作者：Aeschylus（埃斯库罗斯）
   - 英译者：E. D. A. Morshead
   - 来源电子书：*Four Plays of Aeschylus*，Project Gutenberg #8714
   - 说明：已从四剧合集准确切分为独立全文，从 “PROMETHEUS BOUND / ARGUMENT” 至全剧结束。
2. `02_埃斯库罗斯_阿伽门农_Agamemnon.txt`
   - 作者：Aeschylus（埃斯库罗斯）
   - 英译者：Gilbert Murray
   - 来源电子书：*The Agamemnon of Aeschylus*，Project Gutenberg #14417
3. `03_索福克勒斯_奥狄浦斯王_Oedipus_the_King.txt`
   - 作者：Sophocles（索福克勒斯）
   - 英译者：Gilbert Murray
   - 来源电子书：*Oedipus King of Thebes*，Project Gutenberg #27673
4. `04_索福克勒斯_安提戈涅_Antigone.md`
   - 作者：Sophocles（索福克勒斯）
   - 英译者：Lewis Campbell（1906，诗体）
   - 来源：Wikisource，*Sophocles, the Seven Plays in English Verse*；对应 Project Gutenberg #14484
5. `05_欧里庇得斯_美狄亚_Medea.md`
   - 作者：Euripides（欧里庇得斯）
   - 英译者：Edward P. Coleridge（1891，散文体；正文取自 1910 年合集本）
   - 来源：Wikisource，*The Plays of Euripides, Vol. 1*（London: George Bell & Sons, 1910）
   - 说明：译者 1913 年去世，译文属全球公有领域。原书说话人用缩写（Med.、Jas.、Cho.），本文件已统一展开为全名以便阅读，译文措辞未作改动。全剧共 235 段台词，自开场保姆独白至歌队收场白完整。
