# WHU-Robotics Course Materials

武汉大学机器人学院课程资料共享仓库。这里集中整理了机器人学院及相关公共基础课、专业基础课、通识课的课件、历年试卷、复习资料、习题答案与课程评价，方便同学按课程快速查找、备考和补充资料。

> 本仓库资料仅供学习交流使用。请勿用于商业用途，也请在使用试卷答案、回忆版资料或个人整理笔记时自行核对课程要求与授课教师说明。

## 仓库概况

当前仓库按课程或资料类型划分为 12 个主要目录，包含 500 余份文件，主要格式包括 PDF、PPT/PPTX、DOC/DOCX、Markdown、ZIP、视频与表格文件。

## 按类别查找

### 数学基础课

- [高数A上](./高数A上)：适合查找高数 A 上期中、期末真题，重点章节 PPT 和阶段复习资料。
- [高数A下](./高数A下)：适合查找多元函数、重积分、线面积分、无穷级数等相关复习材料与试卷。
- [高数B下-期末](./高数B下-期末)：适合高数 B 下期末复习，包含较长年份跨度的试题和答案。
- [线代A](./线代A)：适合线代 A 期中、期末复习，包含试卷、答题卡、参考答案和综合题解。

### 编程与计算机基础

- [C语言](./C语言)：以考试资料和题库为主，覆盖 C 语言、计算机原理与编程基础、测绘程序设计等相近课程。
- [C语言内容课件](./C语言内容课件)：以系统化课程讲义为主，适合补基础、查语法、复习指针和数据结构相关内容。

### 工程与自然科学基础

- [大物B上](./大物B上)：包含大学物理 B 上的期中、期末资料和部分清晰化整理文档。
- [《机械工程图学习题集》答案](./《机械工程图学习题集》答案)：按章节整理工程图习题答案，适合核对作图题和装配图题。

### 政治、历史与通识

- [近代史](./近代史)：包含近现代史纲要课件整理、复习笔记、参考题与试卷。
- [马克思主义基本原理](./马克思主义基本原理)：包含马原知识点、思维导图、历年试卷和答题模板。
- [英语快班](./英语快班)：包含英语国家社会与文化教材、考点梳理、True/False 练习和写作复习。
- [课程评价](./课程评价)：提供课程评价表格，适合选课前参考。

## 使用建议

1. 先进入对应课程目录，再按年份、题型或资料类型查找。
2. 试卷和参考答案可能来自不同年份、不同任课教师或同名课程的不同版本，请结合当年教学安排判断适用范围。
3. 部分文件名保留了原始来源说明或上传者备注，下载前可先通过文件名判断是否符合需要。
4. 大文件较多，在线预览可能较慢；如需集中复习，可使用 GitHub 的下载功能或克隆仓库到本地。

## 贡献指南

欢迎补充新的课程资料、勘误或更清晰的版本。建议遵循以下规则：

- 按课程名称放入已有目录；如果是新课程，请新建清晰的课程目录。
- 文件名尽量包含年份、课程名、资料类型和是否有答案，例如 `23-24高数A下期末试卷及答案.pdf`。
- 不提交 `.DS_Store`、临时文件、重复文件或无法打开的占位文件。
- 如果替换已有文件，请确认新版本更清晰、更完整或命名更准确。
- 提交 Pull Request 时简要说明新增或修改的课程、年份和资料类型。
